Das ganze System ist einfacher, als es wirkt: Text rein, Text raus. Das Modell tut nur eines – es sagt das nächste Token voraus, immer wieder, bis die Antwort fertig ist.

Es gibt keinen Plan, keine Datenbank, keine Absicht dahinter. Jedes Wort der Antwort ist eine Wahrscheinlichkeitsrechnung über deinen Prompt plus alles, was das Modell bisher geschrieben hat.

Deshalb gibt derselbe Prompt zweimal leicht verschiedene Antworten – und deshalb entscheidet der Prompt so stark über das Ergebnis: Er ist alles, womit das Modell rechnet.

Mehr lesen

Eine Schleife, kein Nachdenken

Stell dir das Modell als eine Funktion vor, die eine Liste von Tokens entgegennimmt und dafür eine Wahrscheinlichkeit für jedes mögliche nächste Token ausgibt. Die Software wählt eines davon, hängt es an die Liste an und ruft die Funktion erneut auf. Das wiederholt sich Hunderte Male, bis das Modell ein spezielles «Ende»-Token wählt. Was du als flüssige Antwort auf dem Bildschirm siehst, ist genau diese Schleife, Token für Token.[[ref:openai-tokens]]

Das Modell «weiss» dabei nicht, wohin der Satz führt. Es hat sich nicht vorher überlegt, was es sagen will. Jeder Schritt sieht nur, was bisher dasteht. Dass daraus trotzdem stimmige Texte werden, liegt daran, dass das Modell aus Billionen von Tokens gelernt hat, welche Fortsetzung in welchem Zusammenhang plausibel ist.

Was das nackte Modell nicht hat

Das Modell selbst hat keinen Internetzugang, keine Datenbank, keine Uhr und kein Gedächtnis über das aktuelle Gespräch hinaus. Wenn ein Chat-Assistent dennoch im Web sucht, deine Dokumente liest oder sich an frühere Gespräche erinnert, dann macht das die Software um das Modell herum: Sie holt Informationen und legt sie – als Text – in den Prompt. Wie das funktioniert, zeigt das Kapitel Kontext mitgeben. Merk dir vorerst: Alles, was das Modell weiss, stammt entweder aus dem Training oder aus dem Prompt.

Warum die Antwort jedes Mal anders ist

Beim Auswählen des nächsten Tokens nimmt die Software nicht immer das wahrscheinlichste, sondern würfelt leicht gewichtet. Das macht Texte natürlicher, aber auch unvorhersehbar. Ein Merkblatt, das du zweimal mit demselben Prompt erzeugen lässt, unterscheidet sich in Wortwahl und Aufbau. Für die Praxis heisst das: Ein guter Prompt macht das Ergebnis besser, nie identisch. Und wenn eine Antwort nicht passt, lohnt sich oft ein zweiter Versuch, bevor du den Prompt umschreibst.

Eingabe und Ausgabe kosten unterschiedlich

Anbieter rechnen Eingabe-Tokens und Ausgabe-Tokens getrennt ab; Ausgabe ist meist deutlich teurer, weil jedes Token einen vollen Durchlauf des Modells braucht.[[ref:openai-prompting]] Für deine Organisation ist das eine Kostenfrage. Für dich ist es ein Hinweis: Lange Antworten sind nicht gratis, und «fasse dich kurz» ist eine sinnvolle Vorgabe – wenn du wirklich nur eine kurze Antwort brauchst.

Die Grenze dieser Einfachheit

Ein System, das nur Text fortsetzt, kann nur mit dem arbeiten, was im Text steht. Fehlt das Reglement, kennt es das Reglement nicht. Fehlt die Anfrage, rät es die Anfrage. Genau diese Beschränkung hat die nächste Entwicklungsstufe ausgelöst: dem Modell den richtigen Kontext mitzugeben. Davon handelt der zweite Teil dieses Kurses.
